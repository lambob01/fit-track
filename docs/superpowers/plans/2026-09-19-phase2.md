# Phase 2 — Feature Expansion Implementation Plan

> **For agentic workers:** Execute task-by-task with the reviewer-subagent loop established in
> Phase 3 of the MVP: implementer leaves changes uncommitted, a read-only reviewer checks the diff
> against spec + plan + `AGENTS.md`, fixes loop until `APPROVE`, only then commit. Escalate only
> for: out-of-scope-list changes, canonical-units/UTC changes, auth-model changes, or security
> issues. No pauses; run to completion; push once at the end after the three pre-push checks.

**Goal:** Ship Phase 2 (weekly calendar, profiles, destructive flows with friction, weight goals,
inline set editing, running tracker, BMI, mobile polish) on top of the MVP.

**Base spec:** `docs/superpowers/specs/2026-09-18-fitness-tracker-design.md` (MVP, still governs).
**Phase 2 spec:** `docs/superpowers/specs/2026-09-19-phase2-design.md` (deltas, authoritative here).

**Tech stack:** unchanged.

## Global Constraints

- Canonical units (kg, m, s, cm) in storage; display conversion only in `frontend/src/lib/units.ts`.
- UTC storage; display via `frontend/src/lib/datetime.ts`; no `toLocale*` outside it.
- UUID PKs; Pydantic IDs typed `uuid.UUID`; session-cookie auth; only `/api/health` and
  `/api/auth/login` are public; auth per router via `Depends(get_current_user)`.
- Nullable goals/values never render or serialize as 0/NaN; unset means omitted/hidden.
- Migrations: one new revision on top of `069cd172c734`; never edit the initial migration;
  downgrade must work.
- Tests: backend pytest with existing `conftest.py` fixtures; frontend Vitest.
- Numeric inputs `type="text"` + `inputMode`, never `type="number"`; tap targets ≥ 44 px.

---

## Required workflow per task

1. Implementer completes the task; changes stay uncommitted.
2. Controller runs `git add -A && git diff --cached > <workspace>/task-<id>-review.diff`.
3. Reviewer subagent reviews that diff against the Phase 2 spec, this plan, and `AGENTS.md`.
4. Fix loop until `APPROVE`; then controller commits with the task's message.

### Task P2: Plans and calendar endpoints

**Files:** Create `backend/app/schemas/plan.py`, `backend/app/routers/plans.py`; modify
`backend/app/main.py`; test `backend/tests/test_plans.py`.

**Endpoints:** exactly spec §1.2. `GET /api/calendar` computes days in the user's timezone
(`analytics.bucket_start(now, tz, "day")` for date labels), matches workouts by local date
converted back to UTC range, and returns adherence counts. `week_start` must parse to a Monday
(422 otherwise).

**Test sketch (real):**

```python
def test_plan_crud_activate_and_calendar(auth_client, exercise):
    t = auth_client.post("/api/templates", json={"name": "Upper A", "exercises": [
        {"exercise_id": exercise["id"], "position": 0, "target_sets": 1}]}).json()
    plan = auth_client.post("/api/plans", json={"name": "Upper/Lower", "slots": [
        {"day_of_week": 0, "template_id": t["id"]},
        {"day_of_week": 3, "template_id": None}]}).json()
    assert plan["is_active"] is False
    assert auth_client.post(f"/api/plans/{plan['id']}/activate").status_code == 200

    cal = auth_client.get("/api/calendar?week_start=2026-09-14").json()
    assert cal["plan"]["name"] == "Upper/Lower"
    assert cal["days"][0]["template_name"] == "Upper A"
    assert cal["days"][1]["template_name"] is None
    assert cal["adherence"]["planned_days"] == 1

    auth_client.post("/api/workouts/from-template/" + t["id"])  # logged today, not week day
    auth_client.post(f"/api/plans/{plan['id']}/activate")       # idempotent
    assert auth_client.get("/api/calendar?week_start=2026-09-16").status_code == 422  # not Monday


def test_second_activate_deactivates_first(auth_client):
    a = auth_client.post("/api/plans", json={"name": "A", "slots": []}).json()
    b = auth_client.post("/api/plans", json={"name": "B", "slots": []}).json()
    auth_client.post(f"/api/plans/{a['id']}/activate")
    auth_client.post(f"/api/plans/{b['id']}/activate")
    active = [p for p in auth_client.get("/api/plans").json() if p["is_active"]]
    assert [p["id"] for p in active] == [b["id"]]
```

Also test duplicate plan name 409, slot replace on PATCH, ownership 404, and completion counted
for a workout logged on the planned local date.
